# GSCAD plugin

Плагин для AutoCAD: исполнительные схемы, оси, размеры, отклонения, рамки.

Вкладка **«ГЕО Схемы»** в ленте AutoCAD. Собран под AutoCAD 2021–2024 (net48).
Для AutoCAD 2025/2026 нужна отдельная сборка под .NET 8 — исходники те же.

## Установка

1. Закрыть AutoCAD.
2. Запустить `dist/install.bat` — копирует `GeoScheme.bundle` в
   `%APPDATA%\Autodesk\ApplicationPlugins`.
3. Открыть AutoCAD — появится вкладка «ГЕО Схемы».

Проверка: команда `GSINFO` показывает версию, единицы чертежа и дату сборки.

## Что уже работает

- **Листы PDF** — палитра с миниатюрами, импорт листа в модель, калибровка.
- **Оси** — ось по обрывкам линий: подгонка прямой, кружок, подпись, слои `GS_`.
- **Объекты** — выделение и перенос на слой `GS_объекты`.
- **Размеры** — вручную (штатный DIMLINEAR) или автоматически по сторонам объекта
  и ближайшим осям; тексты не накладываются, короткие выносятся наружу.
- **Отклонения** — фактические размеры (копия размера с текстом под линией),
  высотные отклонения (число в кружке, предпросмотр за курсором),
  заготовки «Отклонения В/Н» и «Анкера».
- **Рамки** — библиотека DXF с миниатюрами, вставка блоком с масштабом под
  высоту размерного текста, разбиение на объекты, «Подгон шрифта».

## Слои

| Слой | Назначение |
|---|---|
| `GS_подложка` | импортированный лист PDF |
| `GS_оси` | оси |
| `GS_объекты` | объекты схемы |
| `GS_размеры` | размеры |
| `GS_размеры_факт` | фактические размеры |
| `GS_отклонения` | высотные отклонения |

## Сборка

```
dotnet build src\GeoScheme.AutoCAD\GeoScheme.AutoCAD.csproj -c Release
```

Ссылки на `acmgd.dll`, `acdbmgd.dll`, `accoremgd.dll`, `AdWindows.dll` берутся из
`C:\Program Files\Autodesk\AutoCAD 2024` (свойство `AutoCADDir` в csproj).

После сборки в `dist\GeoScheme.bundle\Contents` копируются:

- `GeoScheme.AutoCAD.dll`
- `GeoScheme.Core.dll`
- `PdfiumViewer.dll`
- `x64\pdfium.dll`

## Тесты

dotnet build tests\GeoScheme.Core.Tests

## Команды

| Команда | Что делает |
|---|---|
| `GSINFO` | сведения о сборке и чертеже |
| `GSPALETTE` | палитра листов PDF |
| `GSIMPORT` | импорт листа + калибровка |
| `GSCALIBR` | калибровка выделенного |
| `GSUNITS` | единицы чертежа (м/мм) |
| `GSAXIS` | оси по обрывкам |
| `GSOBJECT` | объекты схемы |
| `GSSELBASE` | выделить подложку |
| `GSSELALL` | выделить всё, кроме подложки |
| `GSSETBASE` | назначить выделенное подложкой |
| `GSDIM` | размеры: вручную или автоматически |
| `GSDIMMAN` / `GSDIMAUTO` | то же по отдельности |
| `GSFACT` | тип отклонений |
| `GSFRAME` | вставить рамку |
| `GSFRAMEEXPLODE` | разбить рамку |
| `GSFITTEXT` | подгон шрифта под штамп |
| `GSTEXT` | текстовые блоки (в разработке) |
