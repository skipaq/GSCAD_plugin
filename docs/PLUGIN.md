# Плагин GeoScheme для AutoCAD

Вкладка **«ГЕО Схемы»** в ленте. Работает внутри AutoCAD 2021–2024 (net48).
Для 2025/2026 нужна отдельная сборка под .NET 8 — исходник тот же.

## Установка

1. Закрыть AutoCAD (иначе DLL занята и копирование не пройдёт).
2. Запустить `dist\install.bat` — копирует bundle в
   `%APPDATA%\Autodesk\ApplicationPlugins\GeoScheme.bundle`.
3. Открыть AutoCAD — вкладка «ГЕО Схемы» появляется сама.

Удаление — удалить папку `GeoScheme.bundle` из `ApplicationPlugins`.

## Команды

| Команда | Что делает |
|---|---|
| `GSPALETTE` | Палитра «Импорт PDF»: миниатюры листов, двойной клик — вставка |
| `GSIMPORT` | Импорт листа в модель + сразу калибровка (без палитры) |
| `GSCALIBR` | Калибровка выделенного: 2 точки + реальный размер в мм |
| `GSAXIS` | Ось по обрывкам: подгонка, проверка, линия + кружок + подпись |
| `GSUNITS` | Единицы чертежа: метры или миллиметры |
| `GSINFO` | Что за чертёж, единицы, версия плагина |

Остальные (`GSOBJECT`, `GSDIM`, `GSFACT`, `GSFRAME`, `GSSTAMP`, `GSPDF`) —
каркасы, пока только сообщают о себе.

## Ось (`GSAXIS`)

1. Выделить обрывки оси — линии и полилинии (можно рамкой).
2. Указать точку марки (Enter — без марки, тогда ось с выступами с обеих сторон).
3. Ввести имя оси.

Плагин подгоняет прямую методом главных компонент, считает максимальное
перпендикулярное отклонение и отказывается рисовать, если разброс больше
0.5% длины (но не меньше 0.01 единицы чертежа) — это защита от «выделил две
разные оси».

Рисует на слое `оси` (создаётся с цветом 72 и типом линии `осевая`, если его
нет): линию, кружок радиусом 0.2 м и подпись высотой 0.15 м. Для чертежей
в миллиметрах — 200 и 150.

Математика вынесена в `GeoScheme.Core` (без зависимостей от AutoCAD) и
покрыта тестами `tests/GeoScheme.Core.Tests`.

## Как устроен импорт

Лист PDF заходит штатным `-PDFIMPORT` (векторы, а не картинка) в точку,
которую указал пользователь, с масштабом 1. Дальше `GSCALIBR`: две точки
известного размера + реальное значение в мм → выделенное масштабируется
вокруг первой точки.

Единицы чертежа хранятся в самом DWG (словарь `GEOSCHEME`), поэтому при
передаче файла коллеге настройка не теряется. По умолчанию — метры.

## Сборка

```
dotnet build src\GeoScheme.AutoCAD\GeoScheme.AutoCAD.csproj -c Release
```

Ссылки на `acmgd.dll`, `acdbmgd.dll`, `accoremgd.dll`, `AdWindows.dll` берутся
из `C:\Program Files\Autodesk\AutoCAD 2024` (путь — свойство `AutoCADDir` в csproj).

После сборки в `dist\GeoScheme.bundle\Contents` копируются:

- `GeoScheme.AutoCAD.dll`
- `PdfiumViewer.dll`
- `x64\pdfium.dll`

## Ограничения тестирования

`accoreconsole` **не поддерживает** `PDFIMPORT` — процесс падает с
`acminidump`. Поэтому всё, что связано с PDF-импортом и палитрой,
проверяется только в живом AutoCAD. Headless-тесты — только для чистой
геометрии и математики.
